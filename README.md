# LINE — Календарь состояний и смыслов

**LINE** — мобильное PWA-приложение для ежедневной практики осознанности. Проект предлагает пользователю одно уникальное «состояние» в день: визуальную метафору в связке с философской цитатой.

### Концепция и процесс разработки

Проект LINE объединяет минималистичный дизайн и возможности генеративных моделей:

1. **Визуальный код:** Разработана система промптов для нейросетей **Recraft** и **Flux**. Создана база из 365 уникальных изображений, выдержанных в единой эстетике скандинавского минимализма.
2. **Работа со смыслами:** С помощью **GPT-4** спроектирована библиотека цитат, которые интегрированы в визуальный ряд и логику приложения.
3. **Frontend:** Чистый JavaScript (ES6+), HTML5 и CSS3. 
4. **Оптимизация:** Логика приложения автоматически синхронизирует контент с текущей датой. Верстка выполнена по принципу **Mobile First** с учетом Safe Areas современных смартфонов.
