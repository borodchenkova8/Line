# LINE — Календарь состояний и смыслов

LINE — это веб-приложение (PWA), созданное для ежедневной практики осознанности. Проект предлагает пользователю альтернативу цифровому шуму: одно визуальное состояние и одну глубокую мысль на каждый день года.

### Как создавался проект (Creative Workflow)

Главная ценность LINE — в объединении системного дизайна и современных AI-инструментов:

1. **Визуальный код:** Я разработала систему настроек (промптов) для нейросетей Recraft и Flux. Это позволило создать консистентную коллекцию из 365+ изображений в стиле скандинавского минимализма, сохраняя единство эстетики весь год.
2. **Работа со смыслами:** С помощью GPT-4 была спроектирована база цитат и философских надписей, которые интегрированы непосредственно в визуальные ассеты.
3. **Frontend-разработка:** Приложение реализовано как Progressive Web App (PWA) на стеке HTML/JS/CSS. 
   * **Логика даты:** Написан скрипт, который автоматически определяет текущий день и показывает пользователю соответствующее "состояние".
   * **Оптимизация:** Реализована система кэширования и мгновенной смены страниц для бесшовного пользовательского опыта.
   * **Native Feel:** Приложение полностью адаптировано под мобильные устройства (поддержка Safe Areas, отсутствие скролла, иконка на рабочем столе).

### Технологический стек
* **Стек:** HTML5, CSS3 (Modern Flexbox), JavaScript (ES6+).
* **Формат:** PWA (Progressive Web App).
* **AI Tools:** GPT-4, Recraft, Flux.
* **Design:** Figma.

LINE — это пример того, как дизайнер может самостоятельно реализовать законченный цифровой продукт, управляя всеми этапами: от генерации смыслов до написания программной логики.
